## 什么时候该更新哪份

| 你改了什么 | 必须同步 | 会被测试卡住吗 |
| --- | --- | --- |
| 新增 / 删除配置项 | `src/models.py::default_settings()` → 本索引里的 `CONFIG.md` 速查表 | 会：`tests/test_docs_config_coverage.py` |
| 发版（改 `metadata.yaml` 版本） | `CONFIG.md` 顶部的「校对版本」+ `CHANGELOG.md` | 会：同一个测试 |
| 新增 / 删除指令 | `menu.md`、`intro.md`、`README.md` 的指令表 | 暂不会（人工检查） |
| 面板视图 / 卡片顺序变化 | `README.md` 功能段、（必要时）本索引 | 卡片顺序有 `tests/test_panel_card_order.py` |
